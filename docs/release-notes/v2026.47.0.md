# HB PDF Studio 2026.47.0

The first release of the Linux AArch64 edition.

- **Pages render in worker processes.** PDFium rendering, tiling and sharpening
  run in a pool of `pdfium-worker` processes instead of the main process, so a
  large drawing no longer blocks the interface and a worker crash leaves the
  app running. The sidecar is built for `aarch64-unknown-linux-gnu` and ships
  in both the `.deb` and the AppImage.
- **One desktop target.** The release builds `.deb` and `.AppImage` on
  `ubuntu-24.04-arm` only; the Windows, macOS, Android and self-hosted web
  bundles are no longer produced.
- **Linux-only code.** The Windows print kernel, the virtual "Open PDF Printer"
  with its spool queue, the Explorer thumbnail and right-click features, the
  Windows certificate store and the platform-specific packaging scripts are
  removed. Printing uses CUPS over IPP, `lp` and the print portal.

This release packages the current default branch. See the GitHub comparison for
other changes since the previous release.
